# Controls

| Action | Input |
|---|---|
| Aim line / shot direction | Mouse X |
| Aim length | Mouse Y |
| Bowl | Space |
| Controlled shot | Left mouse |
| Aggressive lofted shot | Right mouse |
| Completed run | R |
| Cycle camera | Tab |
| Force reset delivery | Backspace |

The mappings are in `Config/DefaultInput.ini` and can later be migrated to Enhanced Input + remapping UI.
